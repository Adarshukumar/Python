# Python-Learning — Adarsh's Python Learning Folder

Author: **Adarsh** — this folder contains original learning notes and runnable
lesson files covering Python from absolute basics to intermediate topics.

## How to use this folder

1. Open `00_ROADMAP.md` and follow the lessons in order.
2. Each `NN_*.py` file is runnable: `python NN_topic.py`
3. Every lesson ends with a short **Practice** section — do it before moving on.
4. Stuck? Check `PYTHON_CHEATSHEET.md` for quick reminders.
5. Want more? `PRACTICE_CHALLENGES.md` has 40 challenges from easy to hard.

## Contents

- `00_ROADMAP.md` — suggested 8-week learning path
- `01`–`24` — core language: variables, strings, loops, data structures, functions
- `25`–`37` — real-world skills: files, JSON, CSV, datetime, regex, stdlib power tools
- `38`–`44` — OOP, decorators, generators, context managers
- `PYTHON_CHEATSHEET.md` — one-page syntax reference
- `PRACTICE_CHALLENGES.md` — 40 practice problems
